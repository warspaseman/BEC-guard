# BEC-guard

Простое приложение для анализа текста электронных писем и поиска признаков BEC (Business Email Compromise) мошенничества, связанного с деловой перепиской. Модель классифицирует письмо как `bec` или `legitimate` и показывает оценку уверенности.

> Это mvp. Результат модели не является гарантией безопасности и не заменяет проверку отправителя, платежных реквизитов и вложений.

## Возможности

 Обучение классификатора на размеченных письмах.
 Оценка качества модели на отложенной выборке.
 Проверка текста письма через веб-интерфейс Streamlit.

## Структура проекта

```text
BEC-guard/
├── app.py                  # Веб-приложение Streamlit
├── train.py                # Подготовка данных и обучение модели
├── requirements.txt        # Зависимости Python
├── dataset/
│   └── bec_dataset.csv     # Датасет писем
└── models/                 # Обученная модель и TF-IDF-векторизатор
```

## Требования
 Python 3.10 или новее.
 pip.

## Установка
Откройте терминал в папке проекта и выполните:

```bash
python -m venv .venv
```

Активируйте виртуальное окружение.

Git Bash:

```bash
source .venv/Scripts/activate
```

PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Формат датасета

Файл `dataset/bec_dataset.csv` должен быть CSV-файлом с заголовками `text` и `label`. В `text` указывается текст письма, а в `label` — метка класса. Например:

```csv
text,label
"Can we move our meeting to 3 PM today?",legitimate
"Please transfer the payment to this new bank account immediately.",bec
```

Добавьте достаточно примеров для каждого класса. Датасет должен содержать реальные строки данных, а не только заголовок; пустой CSV не может быть прочитан для обучения.

## Обучение модели

Из корневой папки проекта выполните:

```bash
python train.py
```

Скрипт выводит примеры данных, отчёт классификации и сохраняет артефакты модели:

 `models/bec_model.pkl`
 `models/vectorizer.pkl`

При изменении или замене датасета запустите обучение повторно.

## Запуск приложения

После того как файлы модели созданы, выполните:

```bash
streamlit run app.py
```

Откройте показанный Streamlit адрес (обычно `http://localhost:8501`) в браузере. Вставьте текст письма в поле **Email content** и нажмите **Analyze Email**. Сам текст письма вводится в браузере, не в терминале.

## Принцип работы

`train.py` делит размеченный датасет на обучающую и тестовую выборки, преобразует текст в TF-IDF-признаки и обучает Logistic Regression. Приложение использует сохранённые модель и векторизатор для классификации введённого текста.

Показанная уверенность это максимальная вероятность, возвращаемая классификатором. Она может быть неточной и не должна рассматриваться как достоверная оценка риска.
